# 公开耗材与 LUT

软件源码维护计算与界面，生产校准数据由 [Lumina-materials](https://github.com/lumina-layer-studio/Lumina-materials)独立维护。源码运行自动连接 GitHub 静态快照，无需用户填写地址、注册 GitHub 或自建耗材服务；打包版自动连接官方托管目录及配套离线资源。两者使用相同包校验和本地资源身份，均按需安装。当前落地与尚待发布／恢复的部分见[资源分发](resource-distribution.md)。

## 首次使用

首次打开时，本地耗材和 LUT 可以为空。耗材选择器用“去云端找耗材”引导用户根据料盘的品牌、系列、色号寻找档案。LUT 选择器用“去云端找 LUT”引导用户核对品牌、颜色模式与配色。点开卡片可预览，点击该条目的下载按钮才会加入本地。回到选择器后保留原来的图片、参数和多选，可以继续勾选使用。已有资料的用户直接从本地列表开始。

打包版附带固定版本的离线目录。有对应包时，用户也可以选“从离线包挑选”，预览条目后点击“添加到本地”。启动、翻页、搜索与预览都不会装入档案。重复添加同一修订会沿用已有记录。自行导入文件和校准也可以作为创建第一份资料的入口。

同次查找在本地选择器、云端和离线包之间保留搜索词，下载后返回本地继续筛选并确认使用。无匹配结果时可清空搜索或筛选；完整目录尚未加载完时不会把暂未找到说成全库无结果。联网失败或使用缓存目录时，有离线包即可从提示处继续查找，无需重新输入品牌和色号。

在“设置 → 常规 → 耗材包装名称”可选择中国大陆包装或国际包装。默认跟随界面语言。品牌中英文名、原档案名、已核实的地区商品名和色号都可用于搜索。切换包装地区只改变显示名称，详情保留档案原名。只有已核实的标志才会显示；缺少对应市场名称的档案继续用原名。

名称、Logo、品牌、材质和使用颜色在本地／云端／离线包中统一呈现。列表保留挑选信息，完整系列、色号、作者、说明和原始名称集中到详情。购买链接只显示资料已有的有效地址，按包装地区选择并展示域名；LUT 可逐通道对应不同品牌及商品页。完整字段规则与两类投稿表单见 [资源资料规则与模板](resource-metadata.md)，投稿与修改流程见 [资源投稿](resource-contributions.md)。

耗材缩略图将黑底、白底的 67 × 34 mm 梯度卡竖放并列。每张有 18 个齐平的方格。两面按相同厚度展示实测色，采样较少的旧档案用空格标出缺项。只有代表色时，详情标注“代表色示意”。

LUT 按打印顺序把文件中的配方 RGB 放回方形校准板，保留实际的空格、留白与定位角标。色格和间隙采用记录的尺寸，缺省时沿用校准工具的默认打印参数。五色基础板为 32 × 32 格，扩展板为 38 × 38 格，两张外形等大。常用八色的 A、B 板各为 37 × 37 格。列表将双板略微错开；详情直接点击色卡，以 360ms 的滑动换卡动画切换，支持触屏及 Enter／空格键，不另设双板切换按钮。名称旁显示当前板名和配方数，单独一页的文件只显示已有的那张。合并或自定义的 LUT 以“配方色表”展示其采样颜色。

云端目录先加载名称、身份与颜色模式等轻量信息，完成后可搜索全部条目。列表以 24 项为基准，按实际列数补齐整行，只为当前页请求色板；回到已浏览的页面直接复用缓存。色板请求失败或返回的修订与条目不一致时，可以在原处重试。旧目录可复用随包中内容哈希相同的预览。条目没有提供色板时，详情标注“暂无色板数据”。浏览和切换色板只读取预览信息，点击“下载到本地”才安装所选 LUT。

Registry 在建立目录快照时，从已校验的 LUT 包生成小型 PNG 色板。普通目录只返回 `lut_board_available`；客户端向 `/luts/catalog` 传入最多 24 个重复的 `preview_id` 获取当前页色板。色板沿用目录的频道和认证规则，支持压缩传输与 ETag；内容不变时返回 304。读取已建立的快照不重复解析 LUT 包。

列表静止时只显示可复用的正面图。移动鼠标时，当前预览随指针轻微转动，可以看到薄边。耗材卡带打印规格时采用其模型厚度，其余耗材卡按 2 mm 示意。移开后回到正视图，触屏可直接滚动和点选。

源码可准备同一固定版本：

```sh
python scripts/prepare_public_resources.py
# 已下载完整资源目录时可断网准备：
python scripts/prepare_public_resources.py --source-dir /path/to/resource-release
```

该命令读取 `assets/resource-release.json`，校验两个包的版本、字节数和 SHA-256，再放入 `resources/materials`、`resources/luts`。当前固定资源 [2026.11.18.1](https://github.com/lumina-layer-studio/Lumina-materials/releases/tag/v2026.11.18.1) 已发布，包含全部已审核公开的 662 份耗材和 99 个 LUT，官方／社区频道按原记录保留。完整耗材合集使用 `lumina_material_seed.json` 1.0，内部保存原分发 ZIP，避免不同资源的同名目录互相覆盖；旧的平铺耗材包仍兼容。两包均含使用说明，用户仍按项添加。

新增原创数据采用 [Lumina 数据协议](../DATA-LICENSE.md)：允许接单打印、销售作品；禁止倒卖数据、收费分发和搭收费资源库。历史版本保留原许可，品牌 Logo 与商标另行授权。

## 从 LUT 试用耗材档案

转换页的经典 LUT 选择器下方首次只显示一行“试试耗材档案配色”。主动阅读、关闭或确认试用后在本机记住状态，转换页整行消失，重新打开不再提示；LUT 库保留“了解耗材档案”手动入口，校准页不重复展示。清除浏览器或应用本地数据后会恢复首次状态。

主动打开说明后，点击“查找我的耗材”沿用耗材选择器，使用已应用 LUT 的结构化品牌辅助搜索；不会按色块猜测耗材型号，也不会自动替用户勾选。取消、下载与浏览都保留当前 LUT，确认后才使用所选耗材并在有图片时生成预览。同一页面会话、同一输入下可点击“返回原 LUT 配色”，恢复原 LUT、层高、层数等来源参数并重新预览；更换输入后不再使用这份返回记录。重新打开应用时，仍可通过颜色来源切回已保存的 LUT 选择。

本地搜索无匹配时，可继续查云端或为耗材建档。现有校准返回流程保留当前多选草稿，保存后点击“加入当前配色”回到选择器，再确认使用。梯度卡生成页可先填写名称和品牌，在当前页面会话中带入提取页；配置包生成后提供“打印并拍照后，去提取”入口。说明统一强调单种耗材复用和兼容耗材组合，层高以实际档案为准，不承诺某种方式总是更准确。

## 更新与存储

启动和每六小时只检查目录，不下载全库。公开目录按来源/查询缓存，断网时显示之前成功的目录和缓存提示；认证错误、无效响应不能被旧缓存掩盖。安装仍重新校验所选 ID/修订、同源地址、包内容和格式。

打包版沿用跨版本共享目录 `materials`、`luts/Custom` 和 `luts/Cloud_sync`。各实例设置和缓存继续独立。移除所有资源后重启仍是空库，可以再次从目录选择需要的条目。

LUT 更新与个人文件冲突时保留原件，新修订写入独立位置。旧项目的生产 LUT 名称只映射到字节一致的迁移资源；找不到该版本时保持缺失状态，由用户明确获取或替换，不自动使用相近名称。

## 发行与服务衔接

Distribution 适配时应从固定应用提交读取资源锁，将两包与源码输入一起冻结，再由 Windows/macOS 装配脚本加入外部资源目录。包验证须检查实际内容、版本描述和重复内嵌材料 seed，旧应用修订保留原有材料 seed 兼容路径；对应装配与真实安装包验收尚待完成。

公开镜像保持现有 `/materials/catalog`、`/packages`、`/luts/catalog`、`/luts/packages` 契约；GitHub 静态目录同时提供单项资源包、预览和统计快照，固定整包用于离线准备；单包安装继续受所选来源的同源与哈希校验约束。账号、投稿和邮箱验证复用独立 Registry，当前本地实现及自动贡献见[资源投稿](resource-contributions.md)。
