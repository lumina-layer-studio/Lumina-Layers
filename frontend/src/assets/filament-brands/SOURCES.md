# Filament branding and packaging names

The UI bundles the marks listed in the table so saved profiles also show them offline. Each trademark belongs to its owner.

`theme/` contains presentation derivatives of these originals, generated by
`python scripts/prepare_filament_brand_logos.py`. Rectangular background mattes
and excess margins are removed. Neutral wordmarks have light/dark ink variants;
selected dark blue/green inks use lighter shades on dark surfaces. Colored
symbols and their palette relationships are retained. These are Lumina's
presentation adaptations, not additional official brand assets. The original
files below remain unchanged. The application selects a bundled variant for
the current theme.

The Bambu Lab table projects the manufacturer's five-digit color code and Chinese and English names for PLA Basic, Matte, Glow, Lite, Translucent, PETG Basic and PETG HF. The package code identifies the color within the manufacturer's catalog. A recorded family and exact color name can also identify a variant. A number in a legacy file name alone does not establish the measured material's family: presentation requires the recorded grade to agree, and curation resolves missing identity from source evidence. [Bambu Studio color catalog, pinned revision](https://github.com/bambulab/BambuStudio/blob/19843bf27197d55fb571e419aa58a29b60bab535/resources/profiles/BBL/filament/filaments_color_codes.json)

Five PLA colors in the [Lumina Registry's official catalog](https://materials.luminastudio.com.cn/api/material-registry/v1/materials/catalog?channel=official) carry CaiLab's AC code. The international labels use the manufacturer's color names for those codes, including Ruby for the calibration named 国旗红 (AC3517). The displayed grade stays PLA as recorded. [CaiLab color options](https://www.cailab3d.com/products/pla-plus-filament-pla-bio-1-75mm-1kg-spool)

For new entries, `display.market_names` accepts `CN` and `INTL`, each containing a packaging name or language-keyed names. `display.localized_names` can supply `zh`, `zh-CN`, or `en` names. `display.aliases`, `sku`, and `color_code` supply searchable identifiers. The original profile name remains available for lookup and attribution. A familiar color descriptor on an otherwise unidentified profile is returned separately as `colorDescription`.
